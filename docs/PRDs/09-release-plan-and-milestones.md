# Release Plan and Milestones - LedgerLens

## Phase 0: Prototype

- PDF text extraction + CSV import
- Canonical ledger + manual category editing
- Local DB + export

---

## Phase 1: MVP Local-First

- PDF OCR fallback
- Categorization model + confidence + explanations
- Correction learning via merchant prior + rules
- Review inbox
- Receipt upload + item extraction + split + settlement
- Desktop packaging + Android APK distribution

---

## Phase 2: Quality and Scale On-Device

- More bank format coverage via templates
- Better dedupe and transfer detection
- Faster OCR pipeline and caching
- Backup/restore locally

---

## Phase 3: Optional Cloud Sync

- Identity + encrypted sync
- Multi-device support

---

## Phase 4: Read-Only Bank APIs

- Aggregator integration
- Continuous import and reconciliation

---

## Phase 5: Assisted Automation

- Bill reminders
- Draft payments
- Suggested transfers with approval
